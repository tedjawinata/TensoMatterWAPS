# TensoMatterWAPS
TensoMatter in web apps version
TensoMater untuk versi web apps

## What is it for
TensoMatter WAPS is used for Tensile/Fabric based simulation for pre-design process of shape or pre-design concept of its structure shape

But web based for Grasshopper plug-in version can be downloaded via;
https://github.com/tedjawinata/TensoMatter
